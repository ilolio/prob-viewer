# prob-viewer

**Token Confidence Viewer** — [llama-server](https://github.com/ggml-org/llama.cpp/tree/master/tools/server) の `n_probs` を利用して、生成されたトークンごとの信頼度（確率）をヒートマップとして可視化するシングルファイルの Web ビューアです。

各トークンは選択された確率に応じて色分けされ（赤=低信頼 → 緑=高信頼）、ホバーすると上位候補トークンとその確率分布をツールチップで確認できます。

## 特徴

- **単一 HTML ファイル**：ビルド不要。`index.html` をブラウザで開くだけで動作します（依存ライブラリなし）。
- **ヒートマップ表示**：トークンの選択確率を HSL カラー（赤→緑）で色分け。
- **候補分布ツールチップ**：各トークンにホバーすると、上位候補（`n_probs` 件）とそれぞれの確率をバーで表示。実際に選ばれたトークンには ✓ マークが付きます。
- **ストリーミング生成**：`stream: true` によりトークンを逐次表示。生成中は **Stop** ボタンで中断可能。
- **モデル選択**：`/v1/models` からモデル一覧を取得してプルダウンで選択。
- **改行の可視化**：改行を含むトークンには `↵` マーカーを表示。
- **文字種バイアス**：ひらがな／カタカナ／漢字／中国語専用文字／アルファベット／数字ごとに、`logit_bias` で出やすさをワンクリックまたはスライダーで調整。**確率を 0 にはしません**。普段は折りたたまれています。
- **旧・新フォーマット両対応**：`top_logprobs`（新しい llama-server）と `probs`（旧版）の両方のレスポンス形式に対応。

## 必要なもの

- `n_probs` に対応した **llama-server**（llama.cpp のサーバー）が起動していること。
- モダンな Web ブラウザ。

## 使い方

### 1. llama-server を起動する

例（ポート `8080`、CORS 許可付き）：

```bash
llama-server -m your-model.gguf --port 8080 --cors-allow-origins "*"
```

> **CORS について**：ブラウザから別オリジンのサーバーへアクセスするため、CORS の許可が必要な場合があります。上記のように `--cors-allow-origins "*"` を付けて起動してください。

### 2. ビューアを開く

`index.html` をブラウザで直接開きます（ダブルクリックまたはブラウザにドラッグ＆ドロップ）。

### 3. 生成する

1. **Server URL**：llama-server の URL（既定値 `http://localhost:8080`）。
2. **Model**：`⟳` ボタンでモデル一覧を再取得し、使用するモデルを選択。
3. **Prompt**：プロンプトを入力。
4. パラメータを調整して **Generate** をクリック（または `Ctrl+Enter` / `Cmd+Enter`）。

## パラメータ

| 項目 | 説明 | 既定値 |
|------|------|--------|
| **Server URL** | llama-server のエンドポイント URL | `http://localhost:8080` |
| **Model** | 使用するモデル（`/v1/models` から取得） | — |
| **Prompt** | 入力プロンプト | `昔々あるところに` |
| **n_predict** | 生成する最大トークン数 | `200` |
| **n_probs (候補数)** | 各位置で取得する候補トークン数 | `5` |
| **Temperature** | サンプリング温度 | `0.8` |
| **文字種バイアス** | 文字種ごとの `logit_bias`（`-5.0`〜`+5.0`） | すべて `0` |

## 文字種バイアス

出力の文字種が偏るとき（日本語のつもりが中国語の簡体字が混ざる、漢字が多すぎるなど）に、
文字種ごとの出やすさを調整できます。内部では llama-server の
[`logit_bias`](https://github.com/ggml-org/llama.cpp/tree/master/tools/server) を使い、
該当する文字をトークナイズした各トークンのロジットにバイアスを加算します。

このセクションは**折りたたみ式**で、既定では閉じています。ヘッダー
（`▶ 文字種バイアス`）をクリックすると開閉します。バイアスを適用していると、
閉じていてもヘッダー右端に `2 種類 適用中` のバッジが出ます（バッジにマウスを
乗せると内訳が表示されます）。折りたたんでいてもバイアスは有効です。

### プリセットボタン

| ボタン | 効果 |
|--------|------|
| **中国語文字を減らす** | 中国語専用文字 `-3.0` |
| **ひらがなを増やす** | ひらがな `+1.5` |
| **カタカナを増やす** | カタカナ `+1.5` |
| **漢字を減らす** | 漢字（日本語） `-1.5` |
| **英字を減らす** | アルファベット `-2.0` |
| **数字を減らす** | 数字 `-2.0` |
| **リセット** | すべて `0` に戻す |

プリセットは**トグル**です。適用中にもう一度押すと解除されます。複数のプリセットを
同時に適用することもできます（例：「中国語文字を減らす」＋「ひらがなを増やす」）。
各行のスライダーで `-5.0` 〜 `+5.0` の範囲を `0.25` 刻みで直接指定することもできます。

### 文字種の分類

| 文字種 | 対象 |
|--------|------|
| **ひらがな** | `ぁ`〜`ゖ`、`ゝ` `ゞ`（88 文字） |
| **カタカナ** | `ァ`〜`ヺ`、`ー` `ヽ` `ヾ`（93 文字） |
| **漢字（日本語）** | 常用漢字を中心とした頻出字（約 1,000 文字） |
| **中国語専用文字** | 日本語では使われない簡体字と中国語特有の機能語（約 640 文字＋語） |
| **アルファベット** | `a`〜`z` `A`〜`Z`（52 文字） |
| **数字** | `0`〜`9`（10 文字） |

「中国語専用文字」には、日中で共通して使う漢字（`国` `点` `来` `面` `里` など）は
**含まれません**。日本語の出力を巻き添えにせず、簡体字（`这` `个` `说` `时` `经` など）と
中国語特有の機能語（`什` `么` `怎` `们` `吗` など）だけを抑制します。
「漢字（日本語）」と「中国語専用文字」は自動的に排他化され、同じ文字に二重のバイアスは
かかりません。

アルファベットと数字は独立した文字種として扱います。片方だけを抑制したり、
逆方向に振ったり（例：アルファベット `+1.75` ／ 数字 `-2.0`）できます。

### 確率は 0 になりません

`logit_bias` は `-Infinity`（llama-server では `false`）を指定するとそのトークンを完全に
禁止できますが、本ビューアはそれを使いません。バイアスは `-5.0` 〜 `+5.0` に制限された
有限の値のみで、抑制した文字も確率が下がるだけで出現の可能性は残ります。
ツールチップで実際の確率変化を確認できます。

すべての文字種が `0` のときは、リクエストに `logit_bias` 自体を含めません。

> **注意**：バイアスは「文字」単位で指定するため、モデルのトークナイザが複数文字を
> 1 トークンにまとめている場合は完全には効きません（例：`です` が 1 トークンの場合、
> ひらがなバイアスは掛かりません）。中国語専用文字については、代表的な語
> （`这个` `什么` `怎么` など）も併せて送ることで補っています。

## 操作

| 操作 | 内容 |
|------|------|
| **Generate** | 生成を開始（生成中は **Stop** に変化し、中断可能） |
| **Clear** | 出力をクリア |
| **文字種バイアスのヘッダー** | クリックでセクションを開閉（既定は閉じた状態） |
| **文字種バイアスのボタン** | 押すと適用、もう一度押すと解除（トグル） |
| `Ctrl+Enter` / `Cmd+Enter` | プロンプト入力欄から生成を開始 |
| トークンにホバー | 上位候補の確率分布をツールチップ表示 |

## 色の見方

トークンの背景色は、そのトークンが選ばれた確率を表します。

- 🔴 **赤（淡い）**：低信頼（モデルが迷いながら選んだトークン）
- 🟢 **緑（濃い）**：高信頼（モデルが確信を持って選んだトークン）

確率情報が得られなかったトークンは灰色で表示されます。

## 仕組み

ビューアは llama-server の `/completion` エンドポイントに以下を送信します：

- `stream: true` でストリーミング応答を受信
- `n_probs` により各トークン位置の候補確率（`completion_probabilities`）を取得
- 文字種バイアスが設定されている場合は `logit_bias`（`[[文字列, バイアス値], ...]` 形式）を送信

受信した各トークンについて、選択されたトークンの確率から背景色を計算し、候補一覧をツールチップ用に保持します。ロジット（`logprob`）で返される場合は `exp(logprob)` で確率に変換します。

## エラー処理

エラー発生時は出力欄下部のステータス行に、失敗した箇所を示すメッセージを表示します（モデル一覧の取得失敗、HTTP エラー、生成中の例外など）。エラーを無視した暗黙のフォールバックは行いません。
